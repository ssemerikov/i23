## 1. Мета та завдання роботи

**Мета роботи:** Набути практичних навичок розробки сучасних адаптивних веб-сторінок з використанням HTML5, CSS3 та фреймворку Bootstrap 5, а також опанувати методи ефективної роботи з Google Gemini для генерації, адаптації та оптимізації коду.

**Основні завдання:**
1. Ознайомитися з можливостями Google Gemini для генерації веб-коду.
2. Розробити структуру веб-додатка згідно з обраною тематикою (мовна академія «Polyglot Academy»).
3. Використати можливості Bootstrap 5 (Grid System, Flexbox, Cards, Accordion, Modal, Navbar, Forms) для створення адаптивного дизайну.
4. Застосувати сучасні CSS-технології (CSS Variables, Grid, Transitions, Shadows, Glassmorphism).
5. Виконати ітеративне покращення проекту: створити окремі детальні сторінки для курсів (`courses.html`), викладачів (`teachers.html`) та відгуків (`reviews.html`).
6. Оптимізувати та адаптувати згенерований AI-код під мобільні, планшетні та десктопні пристрої.
7. Протестувати роботу та функціональність сайту.

## 2. Хід виконання роботи

### Етап 3: Адаптація та покращення
1. **Єдина дизайн-система в `style.css`:**
   - Додано стилізацію хлібних крихт (`.breadcrumb-custom`).
   - Додано стилі для рейтингових зірочок (`.star-rating`).
   - Додано оформлення порівняльних таблиць (`.table-cefr`).
   - Забезпечено однакові відступи, радіуси заокруглення (`border-radius: 1rem`) та тіні карток.
2. **Семантика та доступність (Accessibility):**
   - Використано семантичні теги: `<nav>`, `<main>`, `<section>`, `<article>`, `<header>`, `<footer>`.
   - Додано атрибути `aria-label`, `aria-expanded`, `aria-controls` та `role` для скрінрідерів.
   - Коректна контрастність кольорів згідно з WCAG 2.1.
3. **Інтерактивність без важких залежностей:**
   - Чистий JavaScript для фільтрації елементів та перемикання тарифів.
   - Bootstrap 5 Bundle JS для модальних вікон, акордеонів та навігаційного меню.

---

### Етап 4: Тестування та валідація
1. **Перевірка адаптивності:**
   - Мобільні пристрої (320px – 480px): бургер-меню згортається коректно, картки розташовані в 1 колонку, форми та таблиці масштабуються без горизонтального скролу.
   - Планшети (768px – 992px): сітка перебудовується у 2 колонки.
   - Десктопи (1200px+): 3–4 колонки карток із повною сіткою CSS Grid.
2. **Перевірка функціональності:**
   - Усі внутрішні посилання між сторінками перевірено на працездатність (код 200).
   - Модальні вікна коректно відкриваються та очищують джерело відео при закритті.
   - Форми мають валідацію обов'язкових полів і коректний зворотний зв'язок.
