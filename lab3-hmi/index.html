Як створити файл

Конвертер лежить поруч зі сторінкою:

python3 convert_to_json.py \
    --input ubercorpus.cased.tokenized.word2vec.300d \
    --output model.jsonl --limit 200000

Формат — JSONL: перший рядок містить метадані, далі по одному запису на слово. Такий формат читається браузером потоково, бо повний JSON цієї моделі (~1.7 ГБ) перевищує максимальну довжину рядка у V8.
